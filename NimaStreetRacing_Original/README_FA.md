# Nima Street Racing — X8 Edition (شروع موتور بازی)

این پروژه یک پایهٔ قابل‌ساخت برای بازی مسابقه‌ای سه‌بعدی اندروید است و برای Android 2.3.7 / API 10 هدف‌گذاری شده است.

## ساختار
- `app/src/main/java/.../RaceRenderer.java`: رندر سه‌بعدی OpenGL ES 2.0
- `DrivingPhysics.java`: شتاب، ترمز، فرمان، لغزش و مسافت
- `TouchControls.java`: دریافت هم‌زمان چند لمس
- `CarSpec.java`: کاتالوگ ۲۰ خودرو و مشخصات عملکردی
- `MainActivity.java` و `RaceView.java`: چرخهٔ عمر و سطح OpenGL

## کنترل آزمایشی
- نیمهٔ چپ صفحه: فرمان
- پایین سمت راست: گاز
- بالای سمت راست: نیترو
- بخش میانی/راست: ترمز دستی

## ساخت
با JDK 11، Android SDK platform 28 و Build Tools 28.0.3 و Gradle 7.5:
`gradle assembleDebug`

## نکتهٔ مهم دربارهٔ وضعیت
این نسخه «موتور اولیهٔ قابل‌توسعه» است، نه بازی نهایی NFS Shift. خودروها در این build با هندسهٔ سادهٔ سه‌بعدی رندر می‌شوند؛ مدل‌های دقیق و دارای جزئیات برند، تکسچرهای نهایی، صداهای ضبط‌شده، منو/گاراژ کامل، هوش مصنوعی مسابقه و تست فریم‌ریت واقعی هنوز باید اضافه و آزمایش شوند. فهرست ۲۰ خودرو در کد تعریف شده اما در این مرحله فقط GT-R به‌عنوان خودروی بازیکن و سه رقیب نمایشی رندر می‌شوند.
