Nima Street Racing — Xperia X8 source (مرحله ۰.۱)

هدف این بسته:
- پروژه واقعی Android با Activity و آیکون لانچر
- رندر سه‌بعدی OpenGL ES 2.0
- دوربین تعقیب‌کننده ماشین
- جاده، خط‌کشی، محیط ساده شهری و مدل اولیه خودرو
- کنترل لمسی گاز، ترمز و فرمان
- هدف سازگاری: Android 2.3.7 / API 10

محدودیت مهم:
این نسخه هنوز بازی کامل جهان‌باز یا کیفیت NFS نیست؛ یک پایه‌ی سه‌بعدی قابل توسعه است.
Xperia X8 سخت‌افزار بسیار قدیمی و ضعیفی دارد؛ مدل‌ها، بافت‌ها و نورپردازی باید سبک بمانند.
پیش‌نیاز گرافیکی: درایور گوشی باید OpenGL ES 2.0 را درست پشتیبانی کند.

ساخت با Android SDK قدیمی:
1) پوشه را استخراج کن.
2) در PowerShell به پوشه پروژه برو.
3) اگر ابزار android در PATH نیست، مسیر کامل آن را صدا بزن:
   android update project --path . --target android-10
4) سپس:
   ant debug
5) خروجی معمولاً در bin/NimaStreetRacing-debug.apk ساخته می‌شود.
6) نصب:
   adb install -r .\bin\NimaStreetRacing-debug.apk

اگر ant یا android command شناخته نشد، مسیر نصب Android SDK و نسخه ابزارها را بفرست تا دقیقاً با همان سیستم تنظیم کنیم.

نکته:
برای انتشار نهایی باید debuggable خاموش شود، امضا انجام شود و تست واقعی روی Xperia X8 صورت بگیرد.
