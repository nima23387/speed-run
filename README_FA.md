# Nima Street Racing 1.0.0 — Xperia X8 Edition

این نسخه یک نمونه بازی سه‌بعدی قابل اجرا و قابل توسعه است، با:
- منوی اصلی، گاراژ انتخاب سه خودرو و صفحه اطلاعات
- محیط سه‌بعدی شهری سبک با جاده، ساختمان‌ها و خط‌کشی
- دوربین تعقیب‌کننده و رانندگی با کنترل لمسی
- گاز، ترمز، فرمان و نیترو
- خودروهای ترافیکی ساده
- آیکون لانچر و نام مستقل برنامه
- حداقل Android API 10 و OpenGL ES 2.0

## ساخت APK با GitHub
تمام محتویات این پوشه را در ریشه مخزن `nima23387/speed-run` آپلود کن و commit را به شاخه `main` بزن.
بعد از آن:
1. وارد تب Actions شو.
2. اجرای `Build Nima Street Racing APK` را باز کن.
3. بعد از سبز شدن Build، بخش Artifacts را باز کن.
4. فایل `Nima-Street-Racing-APK` را دانلود و ZIP را استخراج کن.
5. APK داخل آن را نصب کن.

## نکات سازگاری
- هدف ساخت Android 2.3.7 / API 10 است.
- دستگاه باید OpenGL ES 2.0 را از طریق درایور گرافیکی پشتیبانی کند.
- پروژه هنوز روی Xperia X8 فیزیکی آزمایش نشده؛ اجرای موفق روی گوشی تضمین‌شده نیست.
- به دلیل محدودیت سخت‌افزار X8، این بازی گرافیک سه‌بعدی سبک دارد و هم‌سطح کیفیت NFS Payback یا Most Wanted نیست.
- نسخه 1.0.0 در این بسته، نسخه اولیه قابل بازی/پروتوتایپ است؛ برای بازی تجاری کامل هنوز صدا، مدل‌های هنری باکیفیت، فیزیک پیشرفته، مأموریت‌ها، ذخیره پیشرفت و تست عملکرد لازم است.
